## How to Run the Program

1. Make sure Python 3.6+ is installed
2. Place `gamertags.txt` in the same folder as `COMPLETE_GAMERTAGS_PROGRAM.py`
   (a sample `gamertags.txt` is included)
3. Run: `python COMPLETE_GAMERTAGS_PROGRAM.py`

See [`ANSWERS_INDEX.md`](ANSWERS_INDEX.md) for the full directory of all answer files.
